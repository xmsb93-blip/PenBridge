# PenBridge 2.1

- 单击笔键开关草稿纸，0.45 秒内连击只算一次。
- 重压笔尖切换橡皮，抬笔后自动恢复画笔。
- 华图使用 `uinput` 虚拟笔转发，支持笔画中途切橡皮。
- 无障碍连接后自动启动笔控前台服务。
- 使用 Miuix 重构界面，增加笔尖主题图标。
- 补齐 Apache-2.0 许可证和第三方组件声明。

## 安装要求

- Android 8.0 及以上
- root（KernelSU / Magisk）
- 已在小米平板 6S Pro、HyperOS 4 / Android 17 上验证
